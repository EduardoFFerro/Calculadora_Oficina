# 🧮 Calculadora Simples & Guia Prático de Git e GitHub

Este repositório contém uma aplicação simples de calculadora, seu principal objetivo **é servir como laboratório prático** neste minicurso SECOMP 2026 para você dominar os conceitos fundamentais de **Git (linha de comando)** e **GitHub**.

---

## 🎯 Objetivos de Aprendizagem

Ao final desta atividade, você saberá como:
1. Criar um **Fork** de um repositório remoto.
2. Clonar o projeto para a sua máquina local.
3. Criar e alternar entre **Branches** (ramificações).
4. Fazer alterações no código e registrar suas mudanças com **Commits**.
5. Sincronizar alterações enviando commits com **Push**.
6. Abrir um **Pull Request (PR)** para propor suas melhorias.

---

## 🚀 Passo a Passo da Atividade

1. **Faça um Fork do Repositório**  
   No topo direito desta página no GitHub, clique no botão **Fork**. Isso criará uma cópia inteiramente sua deste projeto na sua conta do GitHub.
